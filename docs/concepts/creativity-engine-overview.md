# Creativity Engine Specifications

**Purpose:** Define how DiscussionAgents produce genuinely novel, diverse thinking instead of LLM-typical semantic clustering and polite consensus.

**Core Problem:** Without deliberate mechanisms, AI agents talking to each other will converge on safe, obvious ideas quickly. The creativity engine is the set of traits, techniques, constraints, and injections that make discussions feel like they're between genuinely different thinkers with different stakes, not one LLM using different names.

---

## Documents

### [techniques.md](./techniques.md)
Brainstorming techniques adapted as agent behaviors. How specific creativity methods (SCAMPER, Reversal, Cross-Pollination, etc.) get embedded into DiscussionAgent thinking patterns rather than applied as external exercises.

### [personalities.md](./personalities.md)
Agent personality dimensions beyond simple "assertiveness." Creativity temperature, emotional lens, cognitive style, risk tolerance, domain affinity. How these traits combine to produce genuinely different reasoning patterns.

### [positions.md](./positions.md)
Positional framing -- agents who ARE stakeholders, not agents who "consider" stakeholders. The customer who needs this solved, the investor who needs ROI, the competitor trying to beat it, the regulator who will block it. How position creates authentic motivation and self-interest that drives real disagreement.

### [anti-slop-mechanisms.md](./anti-slop-mechanisms.md)
Specific mechanisms to prevent LLM default behaviors: semantic clustering, premature convergence, polite agreement, restating the same idea in different words, and "sounds great!" responses. Domain pivoting, provocation injection, convergence suppression, and quality gates.

### [phase-dynamics.md](./phase-dynamics.md)
How the creativity engine changes across Phases. Which traits get amplified, which agents come off the bench, what communication modes are active, and how the system progressively shifts from divergent to convergent thinking.

### [research-applied.md](./research-applied.md)
Results from research into additional creativity strategies, cognitive diversity techniques, group dynamics, and approaches from fields outside AI/LLM that could make agent discussions more authentic and productive.
