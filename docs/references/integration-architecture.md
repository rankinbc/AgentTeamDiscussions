## Config Inheritance Chain

    template_dir = _SYSTEM/ / "templates"  ← NOTE: not the engine's templates

engine/config_loader.py
  _loader = ConfigLoader(
    config_dir = _ENGINE_DIR / "config",   ← engine/config/

**Implication:** Engine always uses its own config. The `agentteam` library's default convenience functions are NOT used by the engine — the engine wires its own `ConfigLoader` instance.
