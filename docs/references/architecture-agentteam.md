## Prompt Assembly (prompts/)

### build_system_prompt(agent)

Assembles the full system prompt from three layers:
1. **Identity layer** (`identity.py`) — rendered via `identity.j2` template
   - Name, description, role, drives, pushback_on
   - All 8 personality traits expanded to English sentences
   - Technique name + behaviors
2. **Output layer** (`output.py`) — rendered via `output.j2` template
   - Voice/tone, vocabulary hints, anti-patterns
   - Operating level description (what/why vs. implementation)
   - Job description (propose vs. critique vs. evaluate)
   - Anti-slop rules (agreement tax, perspective enforcement, etc.)
3. **Remember block** — short in-character identity anchor

### build_perspective_reminder(agent)

~50-word inline reminder injected at the start of every turn:
```
[You are {name} -- {role}. Style: {cognitive_style}, {emotional_baseline}. Technique: {primary}. Stay in character. Add substance or stay silent.]
```

### build_context_lens(agent)

Agent-specific attention filter. Focuses the agent on their drives, flags their pushback_on items, applies domain affinities. Injected before discussion context.

### filter_prior_rounds(prior_rounds, agent)

Truncates prior round history for low-patience agents (patience < 0.3) to last 2500 chars.

## Round Orchestration (conversation/orchestrator.py)

### compute_speaking_order(agents, team)

```python
score = assertiveness * 0.5 + intensity * 0.3 + stubbornness * 0.2 + random.uniform(-0.1, 0.1)
```
Higher score speaks first. Jitter prevents deterministic ordering.

### build_agent_payload(...)

Per-agent message payload. Sections assembled in order:
1. Perspective reminder
2. Drift reminder (if drift detected)
3. Context lens
4. Decisions (from brief)
5. Prior design docs
6. Unresolved open questions
7. Discussion so far (prior rounds + this round so far)
8. The question
9. Round instruction (if any, e.g. counter-propose)
10. Speaking position cue ("first" vs "responding to others")

### run_round(...)

Runs one round sequentially. Each agent sees all prior speakers' responses in `this_round_so_far` before generating their own. Callbacks: `on_agent_start`, `on_agent_done`.

## Drift Detection (agents/drift.py)

Two signals checked in `detect_drift(previous_response, agent)`:

1. **Agreement phrases without identity anchors**: If the previous response contains phrases like "i agree", "great point", "you're right" AND doesn't contain any of the agent's identity anchor words (extracted from drives + pushback_on), drift is flagged.

2. **Explicit capitulation phrases** (unconditional): "perhaps you're right", "i'll concede", "i take that back" — suppressed only if agent is still anchored.

When drift is detected, `build_drift_reminder(agent)` injects a targeted <100-word reminder into the next payload.

### Resume Integrity

`hash_question_list(questions)` computes SHA-256 of question numbers + titles. Stored in session status. On resume, hash is compared — if different, session cannot be safely resumed.

## Decision Ledger (session/ledger.py)

Append-only log of `DECIDED:` and `OPEN:` items extracted from each design doc. Format:
```
### Q1: Question Title
- DECIDED: Response truncation uses last-N strategy, keeping first 2 messages
- OPEN: Whether to apply truncation to evaluation rounds
```

`hallucination_check(design_doc, ledger_section)` validates the ratio of ledger decisions to design doc headings is within [0.2, 4.0] to catch runaway or empty ledger extractions.

## Synthesis (synthesis/doc.py)

`synthesize(question, round_responses, round_labels, system_prompt, timeout, ...)` assembles all round responses into a structured user-message, calls Claude with the synthesis system prompt, and returns the design doc text.

Minimum acceptable synthesis: 50 chars. Anything shorter raises `RuntimeError`.

## Config Loader (config/loader.py)

`ConfigLoader` is a class accepting `config_dir` and `template_dir`. Loads YAML configs (cached after first read) and renders Jinja2 templates.

A **default instance** is created pointing to `_SYSTEM/config/` and `_SYSTEM/templates/`. The engine creates its own instance pointing to `engine/config/` and `engine/templates/`.

Key methods: `defaults()`, `experiment_modes()`, `role_overlays()`, `display_name()`, `render_prompt()`, `load_prompt_raw()`, `load_spec_template()`, `load_html_template()`.
