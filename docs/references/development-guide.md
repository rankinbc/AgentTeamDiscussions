## Common Issues

**`claude` CLI not found**
```
[Error: 'claude' CLI not found. Make sure it's installed and on PATH.]
```
Install the Claude CLI and ensure it's on PATH.

**Import errors from `agentteam`**
The package must be installed editably: `pip install -e .` from `_SYSTEM/`.

**Session resume fails with "question hash mismatch"**
The brief was modified after the session started. Start a fresh session or revert brief changes.

**Empty design doc**
Synthesis returned < 50 chars. Usually a Claude timeout or rate limit. Check timeout settings in `defaults.yaml`.

**Agents producing identical responses**
Ensure the experiment mode has distinct `agent_roles` configured, or use a mode with structural contrast (e.g. `counter`, `compete`).
