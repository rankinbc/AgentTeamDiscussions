## Where to Add New Code

**New agent persona:**

**New experiment mode:**
- Add entry to: `_SYSTEM/projects/engine/config/experiment_modes.yaml`

- No Python changes required

**New role overlay:**
- Add entry to: `_SYSTEM/projects/engine/config/role_overlays.yaml` under `overlays:`
- Reference by key in `agent_roles:` within experiment mode config

**New prompt template:**
- Add: `_SYSTEM/projects/engine/templates/prompts/{name}.md.j2`
- Load via: `config_loader.load_prompt_raw("prompts/{name}.md.j2")` in engine code

**New agentteam library feature (types, prompt logic, session I/O):**
- Add module to appropriate `_SYSTEM/agentteam/{subpackage}/`
- Export from `_SYSTEM/agentteam/{subpackage}/__init__.py`
- Add tests to `_SYSTEM/tests/test_{module}.py`

**New engine feature (discussion mode, CLI flag, synthesis step):**
- Primary location: `_SYSTEM/projects/engine/discussion/engine.py` (discussion logic) or `_SYSTEM/projects/engine/session/runner.py` (session lifecycle)
- Config-driven behavior: add YAML key to `defaults.yaml` and read via `defaults()["key"]`

**New team:**
- Create team manifest: `_SYSTEM/data/teams/{team-name}.yaml`
- Create agent files: `_SYSTEM/data/discussionAgents/{team-name}__{agent_key}.yaml` for each agent
- Copy team manifest to engine config: `_SYSTEM/projects/engine/config/teams/{team-name}.yaml`
