## PersonalityConfig

8 float traits in [0.0, 1.0] scale each agent's behavior. Converted to English sentences in the system prompt via `identity.py`.

| Field | Type | Default | Low end | High end |
|---|---|---|---|---|
| `assertiveness` | float | 0.5 | reserved, diplomatic | assertive, fights hard |
| `creativity_temp` | float | 0.5 | conventional, proven-path | wildly creative, novel |
| `risk_tolerance` | float | 0.5 | risk-averse, safety-focused | risk-tolerant, bold bets |
| `attention_span` | float | 0.5 | topic-hopper | deeply focused, drills in |
| `stubbornness` | float | 0.5 | flexible, quick to update | stubborn, holds ground |
| `idea_receptivity` | float | 0.5 | agenda driver | builds on others' ideas |
| `bluntness` | float | 0.5 | diplomatic, softens truths | brutally direct |
| `patience` | float | 0.5 | impatient, cuts tangents | patient, lets it breathe |
| `cognitive_style` | CognitiveStyle | analytical | — | — |
| `emotional_baseline` | EmotionalBaseline | neutral | — | — |
| `domain_affinities` | list[str] | [] | Domain keywords agent draws from | — |

**Speaking order formula:** `assertiveness * 0.5 + intensity * 0.3 + stubbornness * 0.2 + jitter`

**Context truncation trigger:** patience < 0.3 → prior rounds truncated to last 2500 chars

**Receptivity behavior:**
- `idea_receptivity >= 0.7` → "build on what others say" note added to context lens
- `idea_receptivity <= 0.3` → "stay focused on your own framing" note added
