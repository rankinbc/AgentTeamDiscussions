### Soren (solo dev scope warden)

Before geography is locked, the group needs a system count on the table.

Ren's adjacent/separated framing and Max's "one neutral buffer" proposal both imply a galaxy of authored systems. Every system in scope is a content budget line: patrol presence, Bar contacts, mission pool entries, landing pad, faction affiliation, NPC dialogue. On a solo schedule, the difference between six authored systems and twelve is the difference between shipping and not shipping.

Vera asked the right question and nobody answered it. I'll restate it as a build constraint: a solo dev can author roughly six to eight systems with full faction content at the quality level this design requires. If the geography discussion produces a map that needs more than that, the discussion is designing outside the build envelope before the first milestone ships.

The second issue: "sessions 2-3" is a pacing assumption that has no grounding yet. Standing delta tuning isn't authored. Mission reward rates aren't authored. The tooltip fires at 40 — but how many sessions it takes to reach 40 through normal play is unknown until M5 playtest data exists. Geography decisions made against an assumed session-count will need to be revisited against real pacing data.

My input to this question is one number and one constraint: state the total system count before the geography topology is discussed further. And build pacing estimates from the standing delta data we don't have yet rather than from session intuition.

What's the system count?
